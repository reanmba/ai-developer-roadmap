# AI Developer Roadmap

## About This Project

This repository documents my 3-month guided,
project-based learning journey to becoming an AI Developer.

The goal is to develop practical skills in AI Development,
Data Science, Business Analytics, and AI Automation
through real-world projects.

## Learning Objectives

- Build AI-powered applications using Python.
- Understand APIs, JSON, and LLM fundamentals.
- Apply AI to Marketing and Business Analytics.
- Develop AI automation workflows.
- Build and deploy AI applications.
- Develop a professional GitHub portfolio.
